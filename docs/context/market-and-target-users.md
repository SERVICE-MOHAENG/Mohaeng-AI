# 요약

모행이 먼저 해결할 문제는 여행 계획 과정의 결정 피로, 개인 맥락에 맞는 일정 부족, 동행자 간 합의 비용입니다.
초기 핵심 타겟은 여행 계획 부담이 높고, AI 추천과 타인의 일정 참고에 거부감이 낮은 20~34세 사용자입니다.
이 문서는 기능 우선순위, UX 원칙, 마케팅 메시지를 정할 때 사용하는 제품 맥락 문서입니다.

# 배경

여행 정보는 블로그, SNS, 지도 리뷰, 영상 콘텐츠를 통해 과잉 공급되고 있습니다.
정보가 많아질수록 사용자는 후보를 비교하고, 자신의 조건에 맞게 다시 조합하고, 동행자와 합의하는 데 많은 시간을 씁니다.
모행은 이 과정을 AI 일정 초안, 채팅 수정, 타인 일정 참고와 리믹스 흐름으로 줄이는 것을 목표로 합니다.

# 본문

## 문서 목적

- 모행이 누구의 어떤 문제를 가장 먼저 해결할지 명확히 합니다.
- 기능 우선순위, UX 원칙, 마케팅 메시지의 의사결정 기준으로 사용합니다.
- "모두를 위한 서비스"가 되려다 핵심 가치가 흐려지는 것을 방지합니다.

## 서비스 정의

모행은 몇 가지 질문만으로 AI가 개인 맞춤 여행 일정을 만들고, 다른 사람의 일정과 일지를 참고하거나 수정해 내 일정으로 재구성할 수 있는 여행 계획 및 커뮤니티 서비스입니다.

## 핵심 문제

### 1. 선택지 과잉으로 인한 결정 피로

오늘날 여행 정보는 부족하지 않습니다.
사용자는 블로그, SNS, 지도 리뷰, 영상 콘텐츠를 오가며 장소, 숙소, 음식점, 이동 동선을 비교합니다.
후보가 많을수록 "더 나은 선택이 있을 것 같다"는 생각 때문에 결정을 미루고, 계획 시간이 늘어납니다.

### 2. 내 맥락에 맞는 일정 부족

타인의 일정은 참고할 수 있지만 그대로 사용하기 어렵습니다.
여행 기간, 예산, 동행자, 이동 속도, 테마가 조금만 달라도 기존 일정을 다시 수정하고 재조합해야 합니다.
즉, 검증된 일정이 있어도 나에게 맞게 바꾸는 재작업 비용이 발생합니다.

### 3. 동행 여행의 합의 비용

친구, 커플, 가족 여행에서는 선호 차이로 논의가 길어집니다.
"꼭 가고 싶은 곳", "피하고 싶은 곳", "너무 빡센 일정"에 대한 의견이 다를 때, 공통 초안이 없으면 합의가 더 오래 걸립니다.
모행은 먼저 공유 가능한 초안을 만들고, 이후 수정하며 합의하는 흐름을 제공합니다.

## 시장과 사용자 행동 인사이트

제공된 원본 문서와 팀 논의 기준으로 보는 인사이트는 다음과 같습니다.

- 여행 계획 과정에서 사용자는 선택지 과다와 결정 피로를 경험합니다.
- 여행 빈도는 늘고 있지만, 사용자는 준비 과정을 더 빠르고 쉽게 끝내고 싶어 합니다.
- 20~30대 사용자는 AI 추천과 자동화 도구에 비교적 높은 수용성을 보입니다.
- 완벽한 자동 계획보다 "괜찮은 초안"과 "빠른 결정 보조"가 초기 가치에 더 적합합니다.
- 검증된 타인의 일정과 일지를 참고해 내 일정으로 바꾸는 흐름은 결정 피로를 줄일 수 있습니다.

## 타겟 세그먼트

모행은 단순히 "여행자" 전체를 대상으로 하지 않습니다.
여행 계획 방식과 타인 콘텐츠 활용 성향을 기준으로 초기 타겟을 좁힙니다.

| 축 | 낮음 | 높음 |
| --- | --- | --- |
| 여행 계획 부담 | 직접 계획을 즐기거나 부담이 낮음 | 검색, 비교, 동선 조합을 피곤하게 느낌 |
| 타인 콘텐츠 활용 성향 | 다른 사람 일정 참고를 선호하지 않음 | 타인의 일정과 후기를 참고해 빠르게 완성하고 싶음 |

초기 핵심 타겟은 계획 부담이 높고, 타인 일정 활용 의향도 높은 사용자입니다.

## 1차 타겟 사용자

| 항목 | 내용 |
| --- | --- |
| 연령 | 20~34세 중심 |
| 라이프스테이지 | 대학생부터 초중반 직장인 |
| 여행 형태 | 친구, 커플 2~4인 소규모 여행, 일부 혼행 |
| 여행 빈도 | 연 1~3회 이상, 주말/연휴 단기 여행 포함 |
| 디지털 성향 | AI 추천, 자동화, 커뮤니티 참고에 거부감이 낮음 |
| 목표 | 검색과 정리 시간을 줄이고 실패 확률이 낮은 일정을 빠르게 확보 |

핵심 니즈는 다음과 같습니다.

- 내 취향에 맞는 일정 초안이 빠르게 필요합니다.
- 동선, 시간, 테마가 말이 되는 일정이 필요합니다.
- 나와 비슷한 사람의 실제 일정과 여행 일지를 참고하고 싶습니다.
- 좋은 일정은 조금만 고쳐서 바로 쓰고 싶습니다.

핵심 JTBD는 다음과 같습니다.

> 주어진 휴가 기간에 맞춰, 내 취향과 조건에서 실패하지 않을 여행 일정을 빠르게 확정하고 싶다.

> 다른 사람이 이미 검증한 동선과 코스를 참고해 결정 피로를 줄이고 싶다.

## 2차 타겟 사용자

### 콘텐츠 공급자형

여행 일정과 일지를 기록하고 공유하는 성향이 강한 사용자입니다.
이들은 모행 커뮤니티의 UGC 생산자로, 다른 사용자가 참고할 수 있는 일정과 여행 기록을 제공합니다.

### 탐색 및 참고형

일정은 직접 짜는 편이지만 좋은 동선, 핵심 스팟, 테마별 레퍼런스가 필요한 사용자입니다.
이들은 타인의 일정에서 일부를 가져와 자신의 계획에 반영합니다.

## 초기 비타겟

초기 제품 방향을 흐릴 수 있어 우선순위에서 제외하는 사용자는 다음과 같습니다.

- 패키지 여행을 선호해 일정 커스터마이징 니즈가 낮은 사용자
- 여행 계획 자체를 취미로 즐기는 하드코어 플래너
- AI 추천에 강한 거부감을 가진 사용자
- 커뮤니티와 공유를 꺼려 UGC 가치를 체감하기 어려운 사용자

## 대표 페르소나

### Persona A: 결정 피로형 일정 소비자

| 항목 | 내용 |
| --- | --- |
| 프로필 | 29세 직장인 |
| 여행 형태 | 연 2회, 커플 여행 선호 |
| Pain | 숙소와 맛집 후보가 너무 많아 결정을 미루고, 동선을 맞추다 지침 |
| Goal | 30분 안에 그럴듯한 일정 초안을 확보하고 커플끼리 빠르게 합의 |
| 모행 가치 | AI 일정 생성, 채팅 수정, 타인 일정 참고 |

### Persona B: 기록 공유형 일정 생산자

| 항목 | 내용 |
| --- | --- |
| 프로필 | 26세, SNS 활동이 많은 사용자 |
| 여행 형태 | 친구들과 단기 여행을 자주 다님 |
| Pain | 다녀온 뒤 기록이 흩어지고 일정 공유가 번거로움 |
| Goal | 여행 일정과 일지를 보기 좋게 남기고 다른 사람에게 도움을 주고 싶음 |
| 모행 가치 | 일정/일지 정리, 공유, 저장, 피드백 |

## 핵심 사용 시나리오

1. 사용자가 3일 여행 조건에 답하면 AI가 일정 초안을 생성하고, 사용자는 저장하거나 채팅으로 수정합니다.
2. 커플 또는 친구가 각자 원하는 것과 피하고 싶은 것을 입력하고, 공통 초안을 보며 합의합니다.
3. 사용자가 나와 비슷한 취향의 타인 일정을 발견하고, 일부만 수정해 자신의 일정으로 저장합니다.

## 초기 성공 지표

| 영역 | 지표 |
| --- | --- |
| 생성 퍼널 | 일정 생성 완료율, 일정 저장율 |
| 수정 퍼널 | 생성 후 채팅 수정 사용률, 수정 성공률 |
| 커뮤니티 | 일정/일지 조회 후 저장 전환율, 좋아요/댓글 등 상호작용률 |
| 리믹스 | 타인 일정 기반 편집 후 저장 비중 |
| 리텐션 | 여행 전 계획 재방문률, 여행 후 기록 작성률 |

## 검증 계획

- 1차 타겟 6명, 2차 타겟 4명 수준의 1:1 인터뷰를 진행합니다.
- "3일 여행 일정 만들기" 과제를 15분 안에 완료할 수 있는지 사용성 테스트를 진행합니다.
- 계획 소요 시간, 스트레스, AI 수용성, 커뮤니티 활용 의향을 설문으로 확인합니다.
- 일정 생성, 저장, 편집, 공유 흐름의 이탈 지점을 로그로 확인합니다.
