# 요약

모행은 "모두의 여행 계획"을 의미하는 여행 계획 서비스입니다.
사용자가 여행 일정 수립 과정에서 겪는 결정 피로와 정보 정리 부담을 줄이기 위해, AI가 개인의 취향과 조건에 맞는 여행 일정 초안을 자동으로 설계합니다.
Mohaeng-AI 레포는 이 서비스에서 설문 기반 여행지 추천, 로드맵 생성, 채팅 기반 로드맵 수정 기능을 담당하는 FastAPI 백엔드입니다.

# 배경

여행 정보는 부족하지 않지만, 사용자는 블로그, SNS, 지도 리뷰, 영상 콘텐츠를 오가며 후보를 비교하고 동선을 조합해야 합니다.
특히 친구, 커플, 가족처럼 동행자가 있는 여행에서는 선호가 달라 합의 비용이 커지고, 공통 초안이 없으면 논의가 길어집니다.
모행은 몇 가지 질문으로 빠르게 일정의 형태를 만들고, 이후 사용자가 채팅으로 수정하거나 다른 사람의 일정과 일지를 참고해 완성도를 높이는 흐름을 지향합니다.

# 본문

## 프로젝트명

모행, 모두의 여행 계획

## 한 줄 소개

여행 일정 수립에 어려움을 느끼는 사용자를 위해, 개인의 취향과 조건에 맞춘 맞춤형 여행 일정을 자동으로 설계해 주는 서비스입니다.

## 제품 목표

- 여행 일정 계획 과정에서 발생하는 시간 소모와 스트레스를 줄입니다.
- 사용자 취향과 조건을 반영한 일정 초안을 빠르게 제공합니다.
- 동행자와 논의할 수 있는 공통 일정 초안을 만들어 합의 비용을 낮춥니다.
- 다른 사용자의 일정과 여행 기록을 참고해 내 일정으로 재구성할 수 있는 기반을 제공합니다.
- 교내 프로젝트에 머무르지 않고 실제 외부 사용자가 활용할 수 있는 서비스로 확장합니다.
- 2026년 AI EXPO 출품을 목표로 완성도 높은 AI 서비스 사례를 만듭니다.

## 핵심 가치

| 가치 | 설명 |
| --- | --- |
| 빠른 초안 | 검색과 정리 없이 여행 일정의 첫 형태를 빠르게 제공합니다. |
| 개인화 | 기간, 지역, 동행자, 테마, 여행 성향을 반영합니다. |
| 수정 가능성 | 생성된 일정을 자연어 채팅으로 교체, 추가, 삭제, 순서 변경할 수 있습니다. |
| 실제 장소 기반 | Google Places API 등 실제 장소 데이터를 활용해 장소명, 주소, 좌표 신뢰도를 높입니다. |
| 공유와 재사용 | 다른 사용자의 일정과 일지를 참고하고 내 일정으로 재구성하는 경험을 지향합니다. |

## 현재 AI 기능 범위

Mohaeng-AI 레포가 담당하는 기능은 다음 세 가지입니다.

| 기능 | 현재 구현 |
| --- | --- |
| 설문 기반 여행지 추천 | `/api/v1/recommend`에서 설문 선호를 받아 추천 지역 5개를 비동기로 생성 |
| 로드맵 생성 | `/api/v1/generate`에서 여행 조건을 받아 LangGraph 기반 파이프라인으로 일자별 로드맵 생성 |
| 로드맵 채팅 수정 | `/api/v1/chat`에서 자연어 요청을 받아 기존 로드맵의 장소를 교체, 추가, 삭제, 이동 |

세 기능은 모두 즉시 `ACCEPTED` 응답을 반환하고, 실제 처리 결과는 NestJS 콜백 URL로 전달하는 비동기 구조를 사용합니다.

## 브랜드 방향

모행의 브랜드 메시지는 여행 준비의 부담을 줄이고 여행의 순간에 집중하게 돕는 것입니다.
사용자는 몇 가지 질문에 답해 맞춤형 여행 일정을 받고, 마음에 드는 일정은 수정하거나 참고해 자신의 계획으로 완성할 수 있습니다.
커뮤니티 기능은 여행 경험을 공유하고, 다른 사람의 실제 일정과 일지를 탐색하는 방향으로 확장됩니다.
